# Spec-Up-T External Reference Demo 1

This repository is a demo glossary for testing `tref` and `xref` functionality in Spec-Up-T.

## Theme: Greenhouse & Irrigation

This glossary focuses on gardening concepts related to greenhouse cultivation and irrigation systems.

### Terms included:
- **Unique to this glossary**: greenhouse, irrigation, harvest, perennial
- **Shared with other glossaries** (different definitions): soil, compost
- **Same as main boilerplate**: mulch, fertilizer, pruning, seedling, watering

## Usage

This glossary is designed to be referenced from the main Spec-Up-T boilerplate using:

```markdown
[[tref: ExtRef1, greenhouse]]
[[xref: ExtRef1, irrigation]]
```

Read more about Spec-Up-T in the [documentation](https://trustoverip.github.io/spec-up-t-website/).
